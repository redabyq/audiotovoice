# MP3 → голосовое сообщение Telegram

Telegram-бот принимает файлы **MP3**, **WAV** и **OGG**, преобразует их в OGG/Opus и отправляет обратно именно как голосовое сообщение (с привычным круглым плеером Telegram).

Всё нужное для обработки аудио уже находится в контейнере. На компьютере достаточно Docker Compose.

## Быстрый запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather): отправьте `/newbot` и сохраните выданный токен.
2. Создайте файл `.env` рядом с `compose.yaml` на основе примера:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Откройте `.env` и вставьте токен после `TELEGRAM_BOT_TOKEN=`.
4. Настройте доступ при необходимости:

   - `ALLOW_ALL_USERS=true` — бот доступен всем (настройка по умолчанию).
   - `ALLOW_ALL_USERS=false` — бот доступен только пользователям из `ALLOWED_USER_IDS`. Укажите их числовые Telegram ID через запятую, например: `ALLOWED_USER_IDS=123456789,987654321`.

   Узнать свой ID можно через бота [@userinfobot](https://t.me/userinfobot).
5. Запустите бота:

   ```powershell
   docker compose up --build
   ```

После первого запуска достаточно:

```powershell
docker compose up -d
```

Откройте бота в Telegram, нажмите **Start** и отправьте ему MP3, WAV или OGG файлом либо аудиозаписью. В ответ придёт голосовое сообщение.

## Управление

```powershell
# Просмотреть события бота
docker compose logs -f

# Остановить
docker compose down

# Пересобрать после изменения кода
docker compose up --build
```

## Примечания

- Бот использует long polling, поэтому ему не нужны домен, HTTPS или открытые порты.
- При закрытом доступе не добавляйте в `ALLOWED_USER_IDS` имена пользователей (`@name`): нужны именно числовые Telegram ID.
- Ограничение на размер входящего файла задаёт Telegram Bot API; в облачном Bot API обычно это до 20 МБ для загрузки ботом.
- Временные исходники и результат удаляются сразу после отправки сообщения.
